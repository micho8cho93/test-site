WHAT YOU GET

Everything stays on your machines.

Board per project

Backlog, Doing, Review and Done for every repository, plus a Control Center showing what needs you across all of them.

Agents in worktrees

Each run is an interactive session in its own Git worktree. Answer questions, approve actions and send follow-ups from your phone.

Schedule & orchestrate

Plan tasks in a calendar, set priorities and dependencies, and let the controller dispatch them while your browser is closed.

Multiple runners

Pair your own machines and route work by repository access, available agents and capacity.

Git you can trust

Fetch, push, merge and open pull requests with checks that refuse rather than guess. An agent finishing a run never merges.

Private phone access

An embedded Tailscale node reaches the controller from your phone. Nothing is exposed to the Internet.

GET STARTED

One command.

macOS or Linux. It checks the download against its published checksum, sets up the database and a background service, and opens Werkbord in your browser. No Docker, no root.

curl -fsSL https://raw.githubusercontent.com/micho8cho93/werkbord/main/scripts/install.sh | sh

Needs git, plus the claude and/or codex CLI to run agents. Windows support is experimental — see the install guide.
